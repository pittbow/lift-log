# 重訓日誌 — 發布到 GitHub Pages

1. 在 GitHub 建立新 repository（例如 `lift-log`，Public）。
2. 把本資料夾的檔案（index.html、manifest.json、sw.js、icon*.png/svg）上傳到 repo 根目錄。
3. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `/ (root)`，儲存。
4. 約 1 分鐘後網址為 `https://<帳號>.github.io/lift-log/`。
5. 手機打開網址 → 瀏覽器選單「加入主畫面」，之後永遠用主畫面圖示開啟。
